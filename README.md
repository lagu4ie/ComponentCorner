# ComponentCorner

ComponentCorner is a React project I created to practice building reusable components and styling a web application with CSS.

## Features

- Reusable React components
- Header, Hero, ProductCard, and Footer components
- Individual CSS files for component styling
- Multiple product cards using reusable components
- Organized React project structure

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Git and GitHub

## What I Learned

This project helped me learn how React components work and how to reuse the same component with different information. I also practiced passing props, organizing files, and styling individual components with CSS.
